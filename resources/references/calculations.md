# 期权计算口径

在计算或复核 Delta、评分、收益和止盈参数时使用。由模型按公式计算，保留输入、单位、公式及结果；策略明确给出的公式优先。缺失输入不能按零补齐。

## Delta

区分单合约报价 Delta 与持仓 Delta：买入 CALL 的报价 Delta 通常为正，买入 PUT 为负；多仓数量为正、空仓为负，所以卖 CALL 的持仓 Delta 为负，卖 PUT 为正。先核对数据源是否已经包含持仓方向，避免重复取负。参见 [OIC 的 Delta 定义](https://www.optionseducation.org/advancedconcepts/delta)。

`lotSize` 从策略和合约数据取得，不能硬编码 100。组合计算应覆盖已有未平仓头寸及拟议交易；数量变化叠加一次，平仓相应冲减。单合约规则按其要求检查有符号 Delta 或绝对值，不能一律把持仓 Delta 当作单合约 Delta。

模型分别整理交易前后的完整头寸。每项包含有符号合约数量、单合约报价 Delta 和该合约乘数。按以下公式计算变化：

```text
option_share_delta = Σ(有符号合约数量 × 单合约报价 Delta × 合约乘数)
share_delta = 持股数 + option_share_delta
stock_delta = 持股数 / 策略 lotSize
option_delta = option_share_delta / 策略 lotSize
strategy_delta = share_delta / 策略 lotSize
normalized_delta = share_delta / 持股数（持股数为零时为 N/A）
```

持股数须非负，策略 lotSize 和每项合约乘数须大于零，单合约报价 Delta 须在 [-1, 1] 内。无效或缺失输入不能用于批准交易。

`stock_delta`、`option_delta` 和 `strategy_delta` 为按策略 `lotSize` 换算的手数等价。归一化 Delta 是总股数等价 Delta / 持股数；`holdStockNum=0` 时此定义不适用，报告 `N/A`，不能除零或视为零风险。若策略另有现金担保归一化定义，使用其分母并说明；要求归一化检查而口径无法确定时，该项为无法核验。规则未定义归一化区间时不做该区间检查。

### 数据源与公式口径

计算前核实当前数据源的单位、持仓方向、数量和乘数。确认 Delta 是单合约报价、手数等价还是股数等价，是否已包含方向和数量。不能按字段名推断含义，也不能重复乘方向、数量或乘数。

例如合约乘数为 100 时，股数等价 Delta `70` 与手数等价 `0.70` 可能表示同一敞口。先核实范围与单位，再比较服务汇总和独立计算结果。字段含义或头寸范围不清楚时，说明缺口，不套用旧版本映射。

## 评分与收益

规则未定义评分公式时使用助手默认公式：

```text
Liquidity_Factor = min(1, OI / 500) × min(1, Volume / 200)
Score = (1 - |Delta|) × (250 / (DTE + 5)) × (Bid / Strike) × Liquidity_Factor
```

收益计算优先遵循规则中的资金口径；通用年化形式为：

```text
年化收益率 = 总净收入 / 实际占用资金 × 365 / DTE
总净收入 = 每股权利金 × 合约乘数 × 合约张数 − 同一交易范围内的总费用
```

用于卖出候选筛选时，默认以 Bid 估计权利金收入；挂单价格另按报价约定。资金占用按策略的担保/持股口径确定，不能把每股收益直接除以整份合约的资金。百分比只在展示时乘 100；用小数比较时 10% 对应 0.10。DTE ≤ 0、资金 ≤ 0 或费用及资金口径未明时不输出伪精确收益率，说明假设或缺口。

使用服务返回的收益率前，核实报价、资金分母、费用、天数和百分比单位。只有口径一致时才能直接比较；否则按适用规则重算。不能按字段名假定计算公式。

## VIX 与 Skew

先核实当前数据源的 VIX、Skew 定义、单位、到期日和档位含义。按适用策略检查原始指标；综合风险等级不能代替必要输入。

助手默认的 PUT-ATM Skew 口径为：同一到期日中 `|Delta| < 0.25` 的 PUT 平均 IV，减去 `0.40 ≤ |Delta| ≤ 0.60` 的 CALL/PUT 平均 IV。结果单位为百分点，不是 IV 比值。例如 IV 为 95% 与 30% 时，差值为 65 个百分点。

此定义不声明当前服务使用相同算法。只有服务指标的定义和单位一致时，才可与默认阈值 60 比较；否则用完整输入自行计算。输入或定义缺失时，报告无法核验。档位标签不能代替阈值，策略另有定义时按策略处理。

## 日期与报价

用实际到期日、订单创建时间及明确的市场时区计算 DTE 和止盈截止时间。报价需要有效 Bid/Ask（`0 ≤ Bid ≤ Ask`），比例计算的分母须大于零。对无成交量、无 OI、异常 Delta 或异常高收益先核验数据，再按适用规则判断。
