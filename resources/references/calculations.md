# 期权计算口径

计算保留输入、单位、公式与结果。采用当前任务明确的模型，不填入隐藏的投资阈值或默认评分公式。

## Delta 敞口

核实报价 Delta 是否已包含方向、数量和乘数。买入 CALL 报价 Delta 通常为正，买入 PUT 为负；空仓的有符号数量为负。不要重复乘方向。定义参见 https://www.optionseducation.org/advancedconcepts/delta 。

合约乘数来自合约资料，不硬编码 100。按同一时点整理现有持仓和拟议变化，避免重复叠加：

```text
期权股数等价 Delta = Σ(有符号合约数量 × 单合约报价 Delta × 合约乘数)
总股数等价 Delta = 有符号持股数 + 期权股数等价 Delta
```

若展示手数等价，说明所用的正值换算基数。若展示归一化 Delta，说明分母；分母为零时标记不适用，不能解释为零风险。参数含义或头寸范围不明时报告无法核实。

## 收益与成本

明确权利金报价、方向、合约乘数、数量、资金占用和费用范围。报价选择是当前方案假设，不是固定使用 Bid 或中间价。

一种简单年化口径是：

```text
净收入 = 每股权利金 × 合约乘数 × 数量 − 同一交易范围的费用
简单年化收益率 = 净收入 / 实际占用资金 × 365 / DTE
```

仅在资金口径和时间适用时使用；它不是复利收益，也不包括未计入的风险和损益。DTE 或分母不为正时不要输出无效比率。比较服务收益率前核实公式和百分比单位。

## 波动、日期与报价

VIX、IV 和 Skew 的定义、期限、单位与档位含义来自当前数据源和选用方法，不假设统一算法。不内置阈值。

使用实际日期和明确市场时区计算 DTE。检查 Bid/Ask 的有效性和数据时间；异常 Delta、无成交量或异常收益需要核实，不机械视为机会。
