# 策略规则与回退

供期权分析和独立复核共用。实际阈值来自用户确认的适用规则；使用外部规则时，须查询当前来源，不能从示例、旧报告或本文件反推当前策略规则。

## 读取规则

按当前返回结构定位目标策略的完整规则内容，提取适用阶段、Delta、DTE、行权价、收益、流动性、评分、风险档位、财报及退出规则，不能假定服务使用固定字段结构。

对每个适用检查项记录规则要求、来源及实际值，并区分：

- 已定义：采用策略规则，包括明确关闭或豁免某项检查的规定。
- 完全未提及：有下表回退值时使用并标注“助手默认”；没有回退定义时标注“不适用”。
- 已提及但含糊、相互冲突或所需数据缺失：标注“无法核验”，不能当作未定义而回退。

规则查询失败时可以交付已有事实与缺口，但不能批准交易。开仓筛选条件不自动成为阻止平仓的条件；依据当前操作应用相应规则。

## 覆盖与担保

对 CC/CSP 开仓或增加义务的方案，分别核验可用股票覆盖或现金担保，不能用 Delta 合规、策略可卖张数或估算保证金替代。结合当前头寸、已核实的有效开仓剩余量和拟议新增量计算总义务，同一批股票或资金不能重复分配；未成交平仓不提前释放。已扣预占的可用资金不要再次扣同一占用。按合约实际交割义务及资金来源判断，证据不足时不批准对应操作，但继续交付能够完成的分析。

按当前服务说明和实际返回核实持仓范围、订单数量及资金字段含义；不要从缺失字段猜测现金或剩余量。执行能力限制与策略条件分开报告，不为满足接口而放松规则，也不把开仓门槛机械用于平仓。

## 助手默认值

这些是本助手现有约定，不是通用投资标准。仅在规则完全未提及时回退。

| 参数 | 默认值 |
| --- | --- |
| OI | ≥ 100 |
| 成交量 | ≥ 50 |
| 买卖价差 | `Ask - Bid` ≤ 理论价格的 10% |
| 合约评分 | ≥ 0.05；默认公式见 [计算口径](calculations.md) |
| 年化收益率 | ≥ 10% |
| VIX | > 35 时禁止开仓 |
| PUT-ATM Skew | IV 差值 > 60 个百分点时禁止开仓；统一为百分点后与 `60` 比较，见计算口径 |
| 止盈 | 浮盈 ≥ 80%；买回限价为卖出权利金的 20% |
| 止盈截止时间 | 订单创建时间 + (到期时间 − 订单创建时间) / 2 |
| 财报规避 | 到期日落在财报日前 5 天内需规避 |

Delta、归一化 Delta、DTE 区间和风险档位没有通用回退数值；规则未定义就不编造。存在风险档位时按其定义判断，不能仅凭“第 4 档”假定含义。

价差分母以策略规则为准；使用默认值时需要理论价格，不能无提示地换成 Mid。VIX、Skew、财报等适用检查缺数据时属于无法核验，不是通过。财报日期位于合约存续期内也应说明事件风险，是否禁止由适用规则决定。

## 报价、退出与例外

本助手默认采用卖出 Ask、买入 Bid 的限价挂单；用户指定价格和策略约束优先。限价挂单不保证成交。参见 [OIC 的订单与执行说明](https://www.optionseducation.org/referencelibrary/faq/trade-entry-execution)。

止盈价格和截止时间优先按策略规则计算，缺省时才用上表；创建止盈单须确认原订单已成交、可平仓数量充足，且不存在重复止盈。实际成交价格或时间变化时重新核对参数。不提前挂止损单；需要时给出监控提醒。

已有止盈单时，分析照常完成并展示新方案对它的影响；执行前须有用户对该具体方案的确认。会话中已有的同一方案确认可沿用，不能把一般分析请求当作确认。不自动取消或替换已有止盈单。

未达标合约可以作为比较对象，但须明确标为不合规，不进入可执行推荐。不能将价差超标等适用硬约束改成警告后直接批准。
