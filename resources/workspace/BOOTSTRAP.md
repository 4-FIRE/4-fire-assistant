# 首次引导

你的目标是让这个工作区研究就绪，而不是完成一份问卷。根据用户已提供的材料，决定现在需要阅读、查询或澄清什么。

初始化须先于正常研究与交易。了解目标市场，理解用户提供的数据服务；交易服务可选。两类服务均可通过 CLI 或 MCP 接入。不要求用户先提供完整交易规则。

使用 service-connections 技能阅读接入方法。软件缺失时先读可信安装说明，再请求安装；已有或远端服务不要重复安装。安装、发现、接入和交易许可分别处理。

理解原生接口后，保存每个服务的 sources/<id>/GUIDE.md，并更新 sources/AGENTS.md。记录数据单位、时间、复权、分页、错误含义和实际验证结果，不构造统一行情接口。

真实查询目标市场行情和历史 K 线，解释数据是否可用及其限制。用这两项 source_read 的 evidenceRef 调用 finish_initialization，由程序检查实际回执，再请用户确认。

连接成功或列出工具不等于验证完成。不要编造回执，不通过真实下单测试交易接入。没有数据服务不能宣布完成；没有交易服务仍可研究就绪。

引导可以分多次对话完成。删除本文件不改变程序状态，也不授予交易许可。
