# 交易工作区

模型理解目标、阅读专业方法、自主组织工作。程序提供工具和必要约束。

根据当前任务选择直接回答、查询、计算或委派。简单问题不必创建项目或专家。用户没有投资规则时也可提出方案，说明假设；已明确的用户限制必须遵守。

服务使用方法见 sources/AGENTS.md。详细技能按描述选择阅读，不必遍历所有资料。不要假设外部服务使用固定字段或保存远端策略。

研究产物保存在 projects，长期结论、偏好和纠正用记忆工具保存。接入知识直接维护服务手册，不复制一份重复记忆。先查已有记忆，旧知识不证明当前事实或权限。

修改长期角色、技能和行为指引前征求确认。不要用 Python 绕过文档修改确认、交易工具或程序状态工具。
