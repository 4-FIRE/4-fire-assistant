# 投资工作区

这里保存用户的投资资料，供不同 agent 共同使用。先按下面的入口定位相关工作，再阅读所涉目录及其上级的 AGENTS.md。任务涉及投资判断时先查适用目标与约束；没有已登记规则不阻止分析。

- [长期事务](areas/AGENTS.md)：持续维护的投资目标、约束、决策依据和复盘。
- [研究项目](projects/AGENTS.md)：有明确问题与完成条件的研究，包括实验和证据。
- [通用知识](knowledge/AGENTS.md)：跨任务知识与参考资料。
- [服务手册](sources/AGENTS.md)：服务能力、限制及使用说明。
- [专业方法](.agents/skills/AGENTS.md)：共享技能，入口为 .agents/skills/<name>/SKILL.md。
- roles/ 补充 FFA 角色职责；extensions/ 保存 FFA 扩展声明与角色资料。其他 agent 可按任务阅读，不自动取得这些角色或权限。
- scratch/ 保存临时工作；.ffa/ 保存配置和程序状态。

目录导航和 agent 工作约定使用 AGENTS.md；具体项目说明可以使用 README.md。共享链接使用相对路径。可选 SOUL.md 提供工作区定制，存在时阅读；BOOTSTRAP.md 只补充 FFA 的初始化过程。

用当前 agent 提供的文件检索、阅读和编辑工具处理资料。在 FFA 中可用 memory_recall 检索，再用 read 阅读；其他工具可直接搜索正文。新增技能遵循专业方法入口的规则。新建或修改文件前先读取现有内容；发现外部修改时重新读取并整合，保留他人的内容。

详细正文只维护一份，其他位置用链接引用。已确认约束在适用范围内生效；事实保留来源和时间；建议与假设不得写成已确认决策。阶段结论变化或需要交接时，更新所属工作的目标、当前结论、未决问题和必要下一步，不追加逐次操作记录。

只保留能改善后续工作的关键信息。已有准确资料时不复制为记忆。服务知识直接维护对应手册；实验记录保留在所属工作。临时计算成为正式证据时保存完整必要记录并引用，保留旧引用可读。scratch 和历史运行不自动清理。

工作区 .ffa 外的内容允许直接维护。助手修改 .ffa 配置须取得用户确认；程序正常保存会话、任务状态和执行回执无需逐次确认。其他 agent 不改写 FFA 运行状态。专业经验需要依据，用户偏好需要明确指示；实质改变后续行为时说明变化。资料保存不授予交易许可，待办事项不自动启动业务。

各 agent 的会话、凭据和工具配置各自保存，不复制进共享资料。服务手册说明原生 CLI/MCP 用法和必要环境条件，不保存凭据。更换 agent 后先核实所需工具与服务是否可用。缺少 FFA 的受控执行能力时，仅准备交易方案，不绕过独立复核、精确确认或重复发送防护。

## FFA

本节供 FFA 以外的 agent 使用。
从工作区根目录运行 `ffa`。
使用 `ffa --help` 查看 CLI 用法。
运行 `ffa` 后，输入 `/help` 查看交互命令。
