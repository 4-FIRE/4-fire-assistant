# 工作区技能

每个技能使用 <name>/SKILL.md。文件以 YAML front matter 开始，包含 name 和 description；description 说明用途和触发条件。必要脚本、参考资料和模板放在该技能内，以相对路径引用。

方法正文说明目标、条件、判断标准和所需能力。只有某个工具可用时才使用它，不假定所有 agent 都提供 FFA 工具。需要专用环境或服务时写明依赖；缺少依赖时说明缺口，不编造调用或回执。

专业经验保留依据和适用范围，用户偏好保留明确指示。技能不保存会话记录，也不重复保存研究结论。已确认约束留在所属事务，通过链接引用。

FFA 和 Codex 从本目录发现技能。.claude/skills 默认链接到本目录，供 Claude Code 使用；修改正文只修改本目录。其他 agent 的技能加载方式按其实际能力配置。
