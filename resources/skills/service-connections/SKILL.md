# 服务接入

以用户提供的可信资料和当前任务为依据，决定需要阅读、发现或修复什么。不使用固定问卷，不重走已完成工作。

阅读 [连接配置](../../references/connections.md)。使用 Pi 文件和命令工具阅读实际服务文档。缺少软件时先说明安装内容并取得用户同意，不盲目安装远端服务或重复安装已有软件。

模型理解原生接口，不生成统一行情适配层。ffa_configure_source 确认来源后，用 ffa_sources 查看约定，ffa_source_read 进行真实查询。保存 sources/<id>/GUIDE.md，以 sources/AGENTS.md 索引。手册说明能力、单位、时间、复权、分页、错误、限制及实际验证依据。

首次初始化查询目标市场真实行情和历史 K 线，再以两次成功回执请求 ffa_finish_initialization。交易服务可选，不用真实下单验证接入。

后续故障只修复受影响来源。接入变更使旧批准失效；历史手册不证明当前可用，也不授予交易许可。包含交易写入的服务不得通过其他原生 MCP 配置重复暴露。
