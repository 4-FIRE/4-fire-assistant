# 服务接入

本技能需要 FFA 接入工具。交付包括当前凭据下的完整已知能力目录、经用户确认的调用约定和可供后续任务使用的服务手册。

[连接说明](../../references/connections.md) 提供发现顺序、配置字段与调用契约。首次接入按“接入与发现”取得目录；修改已有来源时结合当前配置阅读相关连接与恢复条款。

收集服务的原生说明、命令帮助和可信文档，逐项分析用途、输入输出、前置条件、实际影响及调用关系。资料不足时记录依据与缺口，保持能力不可执行；禁止或不可用的能力也保留在目录中。

用已理解的观察操作验证关键用法，将结果与资料依据整理到 sources/<id>/GUIDE.md，并更新 sources/AGENTS.md 导航。手册内容见连接说明的“服务手册”。验证不执行真实下单或其他业务变更。

需要安装软件时说明内容并取得用户同意。凭据仅使用环境变量引用，不读取或记录其值。
