# 回测

选择能检验当前假设的模型，不要求所有策略使用同一引擎。阅读 [计算说明](../../references/compute.md) 了解运行环境和可选计算库。

明确数据口径、成交时点、资金、费用、滑点及相关市场制度。参数是实验假设，不是用户长期投资规则。

关注未来数据泄漏、幸存者偏差、调参过度和交易可实现性。按问题选择基准、样本外检验或稳健性分析，不机械套固定切分比例。

保留源码、输入或可追溯引用、参数、日志和结果。解释收益与回撤的范围及模型限制；一次历史实验不能证明未来有效。模型不支持某种交易时，说明限制或选择其他方法，不把简化结果当成精确事实。
