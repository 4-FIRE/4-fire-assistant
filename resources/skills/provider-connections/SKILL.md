# 能力提供方接入

本技能需要 ffa 接入工具。交付包括完整已知能力目录、经用户确认的初始工具权限和能力提供方手册。

[能力提供方接入说明](../../references/providers.md) 提供发现顺序、配置字段与调用契约。首次接入按“接入与发现”取得目录；修改已有能力提供方时结合当前配置阅读相关连接与恢复条款。

收集原生说明、命令帮助和可信文档，建立完整目录并提出初始权限。资料不明确的接口使用 ask，不要求逐项分析。MCP 先通过 ffa_configure_provider 确认连接，保存后自动完整发现；取得目录后，仅提交 provider ID 和初始权限建议。CLI 可一次确认连接、完整目录和权限。程序只添加缺失规则，保留已有用户值。禁止或不可用接口仍保留。自动发现失败时区分已注册与未验证，继续完成不依赖连接的资料工作。

用明确用于查询的接口验证关键用法，将结果与资料依据整理到 providers/<id>/GUIDE.md，并更新 providers/AGENTS.md 导航。手册内容见能力提供方接入说明的“能力提供方手册”。验证不执行真实下单或其他业务变更。

需要安装软件时说明内容并取得用户同意。凭据仅使用环境变量引用，不读取或记录其值。
