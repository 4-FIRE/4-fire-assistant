# 协作工作区

本工作区用于投资咨询、研究、学习和沉淀。以下路径均相对工作区根目录。

## 开始任务

1. 从根资料入口定位已有项目或长期事务，读取相关目录的 README.md 和 AGENTS.md。
2. 持续项目先恢复目标、当前结论、未决问题和下一步；旧结论结合当前证据核验。
3. 只加载匹配的技能及其要求的资料。使用能力提供方前，从 `providers/AGENTS.md` 定位对应手册；当前能力与权限以工具查询结果为准。

## 推进与沟通

- 满足目标即可，不增加无必要的文件、代码、流程或抽象，不把研究固化为固定流水线。
- 在当前授权范围内持续推进，沿用已确认的目标和参数。常规、可逆的实现选择自行决定；说明影响结果的假设。
- 只有缺失信息会改变目标、关键结果或授权时才提问。暂停依赖步骤，继续独立工作；连接阻塞时仍可整理目录和手册。
- 需要批准时，先完成已授权准备并提供可审阅结果。若技能要求额外确认或暂停，指出实际读取的文件和条款，区分明确要求与自己的解释。
- 按 ASD-STE100 表达原则使用常用词、短句和一致术语，保留必要条件。答复先给结论，再给依据、验证、未决问题和实际保存路径。

## 文件归属

| 路径 | 内容 |
| --- | --- |
| `areas/<领域>/` | 长期目标、已确认约束、建议、决策和复盘；个人组合信息留在此处 |
| `projects/<名称>/` | 研究过程、代码、实验、证据与结论；软件项目自带依赖、测试和说明 |
| `knowledge/<主题>/` | 可跨任务使用的概念、方法和参考资料 |
| `providers/` | `AGENTS.md` 导航与各 `<id>/GUIDE.md` 手册、覆盖缺口和验证依据 |
| `scratch/` | 临时脚本、下载响应、中间文件与计算产物 |
| `agents/` | 主会话与专家职责补充、自定义专家定义 |
| `.agents/skills/` | 工作区自有专业方法 |
| `.ffa/` | 程序维护的内部状态、权限、目录、回执与调用账本 |

先搜索同主题正文，优先更新原文，按需建目录。详细正文只维护一份，其他位置用链接引用；长期建议引用项目证据，通用方法提炼到 knowledge/。长期知识按主题命名，需要保留历史的研究和决策按日期与主题命名。新正文在相关目录 README.md 加入口链接。

无法从权威源恢复的必要证据，在所属项目保留最小副本或可复现记录，不能只留 scratch/ 链接。历史运行不因位于 scratch/ 就可自动清理，不得删除历史交易记录。

## 成果保存

形成有依据的阶段结论、可复用知识、用户确认的决策，或需要交接、用户明确要求保存时，由主会话自动保存成果文档，无须再次询问。普通问答、零散想法和原始输出不逐轮存档；没有新证据或状态变化时，不为日期或措辞变化重复保存。

- 记录结论、日期、适用范围、必要依据和实际存在的未决问题或下一步。不套空模板，不追加操作流水或重复测试记录；未完成工作只写已有结论与未决问题。
- 区分事实、推断、建议和已确认决策。来源注明链接、文件、版本或日期；用户决策注明确认范围。
- 金融结果保留数据时点、单位和计算来源；回测与计算引用实际运行标识、产物路径及可复现命令或输入。
- 按实际结果记录状态：注册不等于验证，验证不等于执行许可，受理不等于成交。
- 结论变化注明日期和原因，新决策关联被替代记录，保留必要历史。
- 阶段结束或交接时，更新持续项目 README.md 的目标、当前结论、未决问题和下一步。

自动保存只授权成果文档写入，不授权改写组合计划、持仓、交易历史、版本化投资输入或数据库，也不授权下单、额外账本写入、提交、推送或发布。各项操作仍需对应授权，正常调用记录由程序维护。

内部状态通过专用工具维护，不直接编辑 .ffa/，不使用文件工具、Bash 或 Python 绕过受控入口。资料更新后核对相关内部状态，包括 ffa_status 的目标市场；不一致时报告缺口，没有专用入口时不直接改文件。

## 可移植性

脚本从自身或项目位置解析路径，不硬编码机器路径；依赖安装在项目环境中。移动文件或命令时同步引用和示例。

## 验证与版本控制

核对链接、日期、状态、来源、命令、参数和响应字段。已有数值引用计算事实源；公式或代码改变时运行相关验证。固定数据测试与外部服务验证分别报告，本地通过不证明外部行为正确。

只验证受影响行为；必要检查通过后，仅因新修改、失败或未决疑点扩大或重复测试。使用现有工具做分析不触发工具开发测试。使用 Git 时，文档修改运行 `git diff --check`；重命名后搜索遗漏引用。

只纳入长期需要的源码、说明和已授权输入。缓存、日志、临时输出、虚拟环境与机器配置保持忽略；凭据、账户标识和券商配置不提交。
