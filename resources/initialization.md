# 工作区初始化

用户已通过 /ffa init 同意开始或接续初始化。本阶段准备资料、接入能力提供方并验证观察调用；外部业务变更不在本次授权内。

从当前 `cwd` 工作区资料和用户提供的说明取得目标市场与资料位置，保留已有正文。接入能力提供方前，读取包内 [provider-connections 技能](skills/provider-connections/SKILL.md)，按技能完成目录、权限建议、查询验证和手册。初始化阶段尚未自动加载技能；该路径相对上方给出的 ffa 包内资料根目录。

按技能要求处理连接阻塞并分别报告接入结果。未满足以下完成条件时，不请求启用确认。

完成初始化需要：
- 完整已知目录已保存，已注册 MCP 的发现完整，CLI 有资料依据，权限配置有效。
- 目标市场的真实行情和历史 K 线各有一份独立的成功 ffa_provider_call 回执，且仍绑定当前连接与目录。
- providers/AGENTS.md 可导航到相关 providers/<id>/GUIDE.md，手册符合技能中的要求。

交易能力提供方可选；验证使用观察调用。初始化完成前，ffa 角色、技能和 MCP 连接不写入工作区的自动加载配置，以免中断后影响普通 Pi 工作。

根 AGENTS.md 用于资料导航和已确认的工作区约定。areas/ 保存长期目标与结论，projects/ 保存需要保留的研究过程，knowledge/ 保存可复用知识，scratch/ 保存临时计算。包内规则留在包内，分析假设留在对应研究中。

调用 ffa_finish_initialization 提交市场及两个回执 ID，市场须与已确认的工作区资料一致。工具检查资料和连接并请求用户确认。完成后提示用户执行 /reload，并用 ffa_status 核对保存的市场。未完成时退出或重载会暂停初始化，再次 /ffa init 才接续。
