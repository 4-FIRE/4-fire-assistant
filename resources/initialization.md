# 工作区初始化

用户已通过 /ffa init 同意开始或接续初始化。本阶段准备工作区资料，按需接入能力提供方；外部业务变更不在本次授权内。

从当前 `cwd` 工作区资料和用户提供的说明取得用途、目标与资料位置，保留已有正文。围绕学习与知识积累、任务与项目推进、研究与决策支持准备相关资料，不要求用户选择固定分类。

主动引导用户说明已有或希望接入的工具：询问 CLI 命令或 MCP 服务的名称、用途，以及官方文档或现有配置位置。说明可以只提供已知信息，也可以暂时跳过、以后再接入；不要索取密钥、令牌等凭据值。工具信息暂缺时继续准备工作区资料，不反复追问，不为等待工具清单暂停初始化。

用户同意接入能力提供方时，读取包内 [provider-connections 技能](skills/provider-connections/SKILL.md)，按技能完成目录、权限建议、查询验证和手册。初始化阶段尚未自动加载技能；该路径相对上方给出的 ffa 包内资料根目录。按技能处理连接阻塞，分别报告注册、验证、需确认与暂不可执行的内容；工作区启用不证明接口已验证。

工具提供、注册、目录发现、连接验证和手册补齐都不是启用前置条件。缺少信息或连接受阻时，先完成可独立开展的资料准备与接入工作，保留未完成项及后续条件，然后请求工作区启用确认；不得把未完成的接入写成已验证或可执行。

完成初始化需要根 AGENTS.md 提供资料导航和已确认的工作区约定，并由用户确认启用。工具会核对根资料与当前权限配置；权限配置异常仍需处理，不能用跳过接入来绕过安全检查。

外部服务均可在完成初始化后按需接入，包括投资数据和交易能力。初始化完成前，ffa 角色、技能和 MCP 连接不写入工作区的自动加载配置，以免中断后影响普通 Pi 工作。

调用 ffa_finish_initialization 请求完成确认；仅在已确认目标市场时提交 market，并确保与工作区资料一致。不提交行情或历史 K 线回执。工具检查根资料与权限、展示已注册能力，并请求用户确认。完成后提示用户执行 /reload；若提交了目标市场，用 ffa_status 核对保存的市场。未完成时退出或重载会暂停初始化，再次 /ffa init 才接续。
