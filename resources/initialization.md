# 投资工作区初始化

用户已通过 /ffa init 同意开始或接续初始化。本阶段准备资料、接入来源并验证观察调用；外部业务变更不在本次授权内。

从已有工作区资料和用户提供的服务说明取得目标市场、连接方式与资料位置，保留已有正文。先检查服务原生认证和已有 profile，不因凭据字段规则另加认证依赖。来源接入的字段、发现和验证要求见 [连接说明](references/connections.md)。

连接或凭据受阻时，继续完成目录分析、资料整理、手册和可完成的注册；只暂停依赖连接的发现与验证。分别报告已注册、已验证、需确认的变更和暂不可执行接口，说明阻塞原因。未满足完成条件时，不请求启用确认。

完成初始化需要：
- 全部可见能力已有分析。依据不足的能力记录缺口并保持不可执行。
- 目标市场的真实行情和历史 K 线各有一次成功的 ffa_source_read 回执，且仍绑定当前连接。
- sources/AGENTS.md 可导航到相关 sources/<id>/GUIDE.md。手册说明实际数据含义与验证依据，具体内容见连接说明。

交易服务可选；验证使用观察调用。初始化完成前，FFA 角色、技能和 MCP 连接不写入工作区的自动加载配置，以免中断后影响普通 Pi 工作。

根 AGENTS.md 用于资料导航和已确认的工作区约定。areas/ 保存长期目标与结论，projects/ 保存需要保留的研究过程，knowledge/ 保存可复用知识，scratch/ 保存临时计算。包内规则留在包内，分析假设留在对应研究中。

调用 ffa_finish_initialization 提交市场及两个回执 ID，市场须与已确认的工作区资料一致。工具检查资料和连接并请求用户确认；根 AGENTS.md 缺失时会创建简短导航。完成后提示用户执行 /reload，并用 ffa_status 核对保存的市场。未完成时退出或重载会暂停初始化，再次 /ffa init 才接续。

后续资料涉及目标市场变更时，核对 ffa_status 的市场字段，通过专用入口更新内部状态。若没有可用入口，报告资料与状态不一致及入口缺口，不直接修改 .ffa/。
