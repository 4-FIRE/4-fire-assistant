# 完整能力接入与工具权限

本文说明能力目录、文件权限和发送规则。验证边界见[技术设计](technical-design.md#8-验证状态与验收边界)，实施方案见[权限计划](permission-implementation-plan.md)。

## 目录与权限分离

能力目录记录当前凭据可见的全部工具，不按任务、能力提供方名称或业务类别裁剪。目录只保存接口事实、参数绑定和可选结果契约。禁止和不可用接口仍保留。

唯一权限文件为 `.ffa/permissions.json`。tools 以工具唯一 ID 为 key，值为 allow、ask、review 或 deny；default 初始为 ask。操作名使用 encodeURIComponent 编码。只做精确匹配，不增加通配符、优先级、参数授权或配置继承。

接入流程依据能力提供方资料提出初始权限，确认窗口展示连接、工具 ID 和权限。配置只添加缺失规则，保留用户已有值。资料不明确的接口同样使用 ask。用户可手工维护配置，模型不能自行降低权限。

权限不是对能力提供方行为的证明。allow 包括免批准的业务变更，review 表示用户选择的独立复核要求，不以接口名称自动设置隐藏门槛。

## 目录与发现

ffa_discover_provider 使用 MCP SDK listTools 的全部分页，保留原生定义。重复名称、分页错误或取消不能保存为完整发现。范围只限当前连接与凭据。

首次 MCP 配置确认连接，operations 为空。发现不修改权限，新工具使用当前 default。后续配置必须保留完整原生目录，不能改写发现状态、原生定义或可用状态。

CLI 从完整能力提供方文档建立已知目录，记录 coverage.basis 与 limitations；不宣称协议级自动全量发现。没有绑定的接口可保留为不可用。

重新发现保留未变化的原生定义及配置，变化工具替换原生定义，消失工具保留为不可用。发现失败保留旧目录，但禁止调用，直到重新发现成功。每次 MCP 调用前核对全部目录。目录、连接、凭据或权限变化撤销未消费许可。

## 文件与用户维护

PermissionFile 负责文件读写，PermissionService 负责结构校验、精确规则及有效配置变化通知。调用和实际发送前重新读取配置，不使用后台文件监视器，不校验文件哈希。缺失、损坏、非法值或非规范 ID 停止调用并撤销许可。

权限只保存在文件中。运行提示词、技能、共享参考、工具描述和输出只说明权限契约，不暴露存储文件或引导模型手工编辑。工具输出展示最终权限，不在数据库或能力提供方手册另存权限配置。接入提交的权限建议先展示，经用户确认后添加。确认期间配置变化则拒绝保存；不要同时手工编辑文件。

模型只通过 ffa_configure_provider 提交初始权限建议，程序负责创建与保存文件。Pi write/edit 直接修改权限文件被拒绝。用户可以在外部编辑器手工维护。Bash、Python、其他扩展及本地用户仍有宿主权限，不声称强隔离。

## 调用

- ffa_provider_call：allow 直接调用；ask 请求本次批准；review 提示先准备与复核；deny 拒绝。
- ffa_prepare_call：保存精确参数、绑定和当前权限，不发送。
- ffa_execute_call：检查当前请求内准备、必要复核和实际发送许可；allow 不请求批准，ask 和 review 请求批准。

专家使用同一调用服务，ask 的批准交给主会话用户；review 不作为专家证据入口递归调用。复核只能引用该专家本次取得的成功回执。

所有调用使用发送前记录及单次传输许可。回执与意图可靠保存，一个意图不重发。新的直接调用是新的显式请求，不能因超时或脚本错误自动创建新请求重发。

可选 outcomes 用于判断业务受理或拒绝。没有结果契约时，只记录协议完整返回，不证明业务完成。传输失败、业务回执冲突或缺失保持未知。未知记录阻止新的 review 调用；allow 和 ask 可以继续核对事实，也可能有副作用。直接调用结果不明时返回带意图 ID 的错误，已取得的回执仍保存，不能报告为未发送。删除业务分类后，不声称仍能阻止全部业务变更。

## 宿主与兼容边界

ffa 管理的 MCP 使用私有连接，不向 Pi 注册原生工具，不显示在 /mcp。其他 Pi MCP 能力提供方不变。本地代码、Bash、Python 和扩展不是沙箱。

当前工作区格式为 ffa-pi/1，业务数据库版本为 1。旧格式直接拒绝，不转换、不补默认字段，不自动迁移、重建或删除用户资料和历史记录。

初始化检查完整目录、权限文件、资料与当前真实行情及历史回执，不要求逐项能力分析。

## 验证

本地使用真实文件、SQLite、CLI、Pi SDK 与确认组件。验证四种权限、默认值、精确 ID、用户规则保留、配置损坏、调用和确认期间修改、取消、绑定失效、单次发送与人工结案。

外部 MCP 分页、列表通知、动态变化、真实模型初始化和专家批准的宿主交互仍需获准环境。完整存储故障及进程终止场景尚未完成验收。
