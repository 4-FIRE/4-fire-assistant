# 使用 Pi 扩展，不再维护独立 CLI

用户确认将 FFA 改为按投资工作区启用的 Pi 扩展包，直接使用 `pi` 及其原生会话恢复。独立 CLI 与 pi-durable 方案要求维护终端、配置和任务运行机制；这些职责偏离投资能力建设，因此删除，不在扩展中保留第二个主运行时。

## 取舍

接受 Pi 原生恢复，不再保证研究任务从原工具调用位置恢复。保留角色、专业方法、必要工具与交易约束；交易账本必须独立于聊天分支，未知执行结果不得自动重发。

包安装不等于工作区启用。初始化由用户显式执行 `/ffa init`；未开始或中断时仅提示，不接管普通 Pi 工作。初始化完成后，从根目录启动即自动启用，但不自动开展业务。

不兼容旧命令、配置、会话、数据库和自定义扩展格式。旧代码、测试与文档只作参考，没有新用途的内容删除；用户资料与历史交易记录不属于删除范围。

本决定已获用户确认，代码已切换到 Pi 扩展，外部服务和真实模型行为仍需验收。目标边界见[技术设计](../technical-design.md)，实施与删除范围见[迁移清单](../migration-plan.md)。
