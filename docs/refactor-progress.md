## SDK 适配边界

技能加载函数只负责文件与提示，不接管任务调度。文件工具直接使用 durable 的 NodeExecutionEnv。

codemode 直接调用当前角色工具，不走编码代理的扩展钩子。因此，必要守卫放在工具入口，而不是只放在钩子中。脚本内禁止专家委派；主助手直接调用可恢复的 delegate_expert。

脚本和 Python 都标记 unsafe，不自动重放。脚本失败不回滚副作用。read_codemode_run 和 research_list 提供实际记录，供模型判断下一步。

未增加文件内容哈希校验。SQLite 保留 WAL/FULL，操作身份摘要与文件校验是不同用途。
