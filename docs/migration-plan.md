# Pi 扩展迁移与验收记录

代码已切换到原生 Pi package，独立 CLI 与 durable 运行时已删除。本文记录剩余验收边界，不保留旧接口兼容清单。

目标与约束见[技术设计](technical-design.md)，取舍见 [ADR](adr/0001-use-pi-extension.md)。

## 已删除

- 独立 `ffa` 命令、终端渲染、快捷键、登录和模型配置界面。
- Harness、WorkDoc、TeamDoc、submission、旧会话索引与升级入口。
- 私有 codemode、脚本重放和通用任务运行时。
- 旧工具端口、固定分层装配、自定义 extension.json 协议。
- 旧工作区模板、其他宿主的自动别名与配置创建。
- 旧 Node 测试及其 CLI、durable、终端辅助进程。
- 旧 CLI 配置说明、旧优化计划和重复运行提示词。
- pi-durable、chord、pi-codemode 和 pi-tui 的直接依赖及旧 overrides。

Pi 自身可能间接依赖 chord 或 codemode；这不表示 FFA 仍保留相应运行时。

不兼容历史工作区、配置、会话、数据库、命令或扩展格式，不建立 legacy 目录或格式适配。用户资料与历史记录不属于清理范围。

## 当前实现选择

- 用户完成初始化后执行一次 Pi 原生 `/reload` 刷新资源；以后启动自动启用。工具内不调用仅限命令上下文的重载 API。
- 同一工作区的活跃 FFA 实例独占业务存储；普通未启用 Pi 不取得该锁。
- FFA MCP 统一使用私有连接，目录包含所有可见工具。所有原生调用在实际传输入口消费单次许可，变更还须可靠落账。FFA 来源不出现在 Pi /mcp；不实现 OAuth 管理。
- 独立复核使用新专家上下文；普通研究员支持凭当前分支引用追问。
- 计算环境由标准 Python/uv 工具准备，FFA 只确认解释器路径，不重建软件安装平台。
- 普通 Python 运行限时 30 秒、输出 2 MiB；超限不报告成功。中断记录不自动重放。
